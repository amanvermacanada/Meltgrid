# Keyword Data Validation Findings

Validation pass requested on the 628-row raw Keyword Planner export (`raw-keyword-exports/MeltGrid_Google_Keyword_Planner_Raw.csv`) and the pre-categorized opportunity workbook (`raw-keyword-exports/MeltGrid_Keyword_Opportunities.xlsx`), run against `04-keyword-research.csv` (the 139-row strategic master this research maintains) and the new `04a-top30-keyword-opportunities.csv`. This replaces the geographic framing in the original `04-keyword-research-notes.md`, which is still accurate but is restated more explicitly here per this round's request.

## 1. Duplicate keywords

**No exact duplicate keyword rows exist in the raw 628-row export** (checked case-insensitively; 0 found). What looks like duplication is really ~15-20 near-synonymous phrasings per real concept (e.g. 9 different "heated driveway [near me/contractors/companies/installers]" variants) — this is normal Keyword Planner "Discover new keywords" behavior, not a data error, but it means a literal keyword count overstates how many distinct content needs exist. See §4, "clustering."

## 2. Irrelevant / off-topic searches found and excluded

Two groups of keywords in the raw export are not real opportunities for MeltGrid's installed-system coordination business, and have been excluded from `04a-top30-keyword-opportunities.csv` and flagged with a `relevance_flag` column in `04-keyword-research.csv`:

- **DIY retail-purchase intent (67 rows, ~4,550/mo aggregate):** searches like "heattrak mats," "heated driveway mats home depot," "snow melting mats amazon," "warmlyyours costco." These searchers want to buy a portable, plug-in mat product off a retail shelf — a completely different purchase (and price point) from a permanently installed snow-melting system. Targeting this traffic would bring visitors MeltGrid cannot realistically convert into a design/installation enquiry. **Correction to the first research pass:** the earlier executive summary stated "'heated driveway mats'-style phrasing carries ~6,250/mo real demand, unaddressed" — that number came from a High-Keyword-Planner-tier subset that happened not to include the worst retail-intent terms, but the *broader* mats/pads cluster in the full 628-row data (212 rows, 17,700/mo) is heavily diluted by this same retail intent (750/mo is explicitly Amazon/Costco/Home-Depot-qualified, and a further unknown share of the "generic" remainder is almost certainly the same searcher just not naming a retailer). Treat the mats/cable cluster as a smaller, genuine opportunity than first stated — useful for a differentiation note on `/technology/` ("the difference between a portable mat and a professional installed system"), not as a primary lead-gen target.
- **Hydronic-manufacturer brand names (2 rows, 100/mo):** "uponor quick track installation," "uponor fast trak installation." Real but tiny volume, and MeltGrid has no confirmed Uponor partnership — do not build content targeting a manufacturer's own branded installation guides.

**Kept, but flagged low-priority rather than excluded:** WarmlyYours-branded searches (29 rows, ~1,650/mo — e.g. "warmlyyours," "warmly yours heated driveway"). Unlike HeatTrak/retail terms, WarmlyYours **is** MeltGrid's actual electric equipment partner, so this traffic is topically relevant. It's flagged low-priority rather than excluded because directly targeting a supplier's own brand name is weak SEO value (WarmlyYours' own site will out-rank anyone else for its own name) — better used as a one-line "we design with WarmlyYours technology" mention on existing pages than as a dedicated target.

## 3. Questionable metrics found

- **21 rows show a 900% three-month change** (e.g. `heated driveway`, `driveway warmer`, `heater for driveway`, `heated driveway cost ontario`). A 900% jump in a single quarter for a mature home-improvement category is a real seasonal signal worth noting (snow-melting searches spike hard as winter approaches — this data was pulled in late October), not a data error, but it means the "5,000/mo" figures for these terms are **current-season, not a flat year-round average** — expect them to be much lower by spring. Treat them as "what demand looks like right now, entering winter," which is actually the most useful framing for a plan being executed over the next 30-90 days.
- **No rows had internally inconsistent fields** (e.g., "Unknown" competition with real bid data present) — checked and none found; this part of the data is clean.
- **Many "Local" rows carry no bid data at all** (empty low/high bid) despite having a volume and competition rating — this is normal Keyword Planner behavior for lower-volume geo-specific queries (too little auction activity to estimate a bid), not an error.

## 4. Discrepancies between the raw CSV and the pre-categorized opportunity workbook

The workbook (`MeltGrid_Keyword_Opportunities.xlsx`) adds a `Topic/Category` column on top of the raw export. **One systematic tagging bug was found and corrected:** the workbook tags `heated driveway brampton` as `Commercial / Property Management` — almost certainly because whatever script built that categorization matched the substring "ramp" inside "b**ramp**ton" the same way an early version of this research's own merge script did (caught and fixed here; see the code comment in the regenerated `04-keyword-research.csv`). The same apparent bug also pushed `heated ramp`, `heated ramp mats`, and `heated ramp system` into the Commercial/Property-Management bucket in the source workbook, when a homeowner searching "heated ramp" is a residential accessibility query, not B2B. **This research's `04-keyword-research.csv` no longer trusts the workbook's `Topic/Category` field for the residential/commercial split or the pedestrian-vs-commercial category assignment — it re-derives both directly from the keyword text with word-boundary-safe matching, and is the corrected source of truth going forward.** The raw Keyword Planner metrics themselves (volume, competition, bid range) are untouched and were not in question — only the added categorization layer had this bug.

## 5. Geographic targeting — corrected framing (restated from the first research pass, now emphasized per this round's request)

**Every "Canada (national)" volume number in this dataset is a national ceiling, not a GTA estimate.** This is not a new finding — the first research pass already flagged it — but it's restated here because it changes how the Top 30 list should be read:

- `heated driveway` and `heated driveway cost` at 5,000/mo each are **all of Canada**, not the GTA. The GTA is MeltGrid's primary market and a large share of Canadian demand for this category plausibly concentrates in Ontario (it's the most populous province and has the right winter climate), but there is no data point in this export that isolates that share.
- The only rows with an explicit `Local –` geography are the 17 `local_gta` seed-batch rows (plus the small number of rows the workbook separately recomputed) — Toronto, Ontario, Ottawa, Mississauga, Brampton, Vaughan, Markham, GTA. Of those, only `heated driveway cost ontario` and `heated driveway cost toronto` (500/mo each) show real, sizeable volume; everything else in that set is 50/mo or smaller.
- **Do not read the ~20,550/mo "core driveway" or ~13,750/mo "cost" category totals in the first research pass as GTA numbers** — they are national aggregates presented that way for prioritization purposes, and this document corrects that framing explicitly. A true GTA-only Keyword Planner pull (location selector set to the GTA specifically, not Canada) remains an outstanding task — see `04-keyword-research-notes.md`'s original "outstanding gap" note, which still applies.

## Net effect on prioritization

None of these corrections change the top-line strategic conclusions from the first research pass (cost content and the core driveway term are still the largest real opportunity; hydronic is still real-but-modest and strategically important; city-level pages still aren't justified by the real local numbers). They tighten the data: the mats/cable opportunity is smaller and more narrowly scoped than first stated, the brampton/ramp commercial mistag is fixed, and the "Canada-wide ≠ GTA" distinction is now explicit wherever a number is quoted in `04a-top30-keyword-opportunities.csv` and `05-content-architecture-and-roadmap.md`.
